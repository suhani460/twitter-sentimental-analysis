# Twitter Sentiment Analysis Using PySpark

## Project Overview
This project analyses Twitter data to identify public sentiment using Big Data processing techniques and Machine Learning.

The project uses the Sentiment140 dataset containing approximately 1.6 million tweets and classifies them into Positive and Negative sentiments.

## Technologies Used
- Python
- Apache Spark (PySpark)
- Spark MLlib
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Dataset collection and loading.
2. Data cleaning and preprocessing.
3. Text tokenization and stopword removal.
4. TF-IDF feature extraction using HashingTF and IDF.
5. Sentiment classification using Logistic Regression.
6. Model evaluation using Accuracy, Precision, Recall and F1 Score.
7. Data visualization and sentiment analysis.

## Key Features
- Processes approximately 1.6 million tweets.
- Performs distributed-data-processing style operations using Apache Spark.
- Identifies positive and negative opinions.
- Generates sentiment distribution charts.
- Visualizes frequent words.
- Evaluates machine learning performance using a confusion matrix.

## Dataset
Sentiment140 Dataset – 1.6 million tweets.

## Project Outcome
A Big Data sentiment analysis pipeline that processes Twitter data, classifies sentiments and presents analytical results through visualizations.
